PWR

电源灯

初始化…

自动模式：网线插上（链路通）→ 绿灯常亮；没插网线 → 红灯闪烁。强制全灭优先级最高，固件升级 / 自愈重装都不会推翻。

DSK

硬盘灯

自动：无盘全灭 / 有盘绿灯常亮

自动模式由 sata-led-manager 接管，无需调节；强制全灭后无论有盘无盘均熄灭。

BUZ

蜂鸣器

时长保存在 /etc/s2hwctl/beep.conf，开机提示音与长按关机蜂鸣均使用该时长。

FAN

风扇控制

—

右侧「挡位」滑块仅在 手动挡位 模式下可拖动；其余模式由温控自动决定挡位。

THERMAL CURVE · 自动温控（固定曲线，不可调）
CPU 50~60℃ → 最高 5 档 CPU 60~70℃ → 最高 10 档 CPU 70~80℃ → 10~15 档 硬盘 40/50/55/60℃

自动温控采用固定阈值，不可调节。需自定义请切到「手动控温」。

THERMAL CURVE · 手动控温（自定义曲线，仍自动调速）

自定义 CPU / 硬盘温度阈值，保存后仍由温控自动调速（非固定挡位）。

「手动挡位」模式：拖动上方滑块直接设定固定风扇挡位（0 = 停转，15 = 全速），立即生效，保存后重启保留。

风扇取「CPU 曲线」与「硬盘曲线」中较高的挡位；保存写入 /etc/fan-control.conf，重启后依旧生效。

PWR

定时开关机

关机为每日到点自动 poweroff；开机依赖主板 RTC 定时唤醒（需 NAS 常通电）。

NET

访问端口

写入 settings.conf 后自动重启；若通过应用中心打开，请改用新端口访问。
